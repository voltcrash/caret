# Basic contributions

You can improve Caret themes, languages, quotes, layouts, and documentation through GitHub without running the app locally.

1. Fork [voltcrash/caret](https://github.com/voltcrash/caret) to your GitHub account.
2. Edit the relevant file in your fork. GitHub's web editor works for small changes.
3. Open a pull request back to `voltcrash/caret` on `main`. Describe what changed and why.

For application changes, use the [development setup guide](./CONTRIBUTING_ADVANCED.md). See the focused guides for [themes](./THEMES.md), [languages](./LANGUAGES.md), [quotes](./QUOTES.md), [layouts](./LAYOUTS.md), and [fonts](./FONTS.md).

Open an [issue](https://github.com/voltcrash/caret/issues) if you need help.
