Offline Oxytype terminal release using the same Rust typing engine as the website.

- Bundled English words/original quotes; time, words, quote, custom/file and zen.
- Native input/scoring, Unicode cell rendering, explicit keyboard limitations.
- Durable private local history, settings, native validity/PBs and JSON export.
- Replay logs opt in explicitly; no accounts, sync, telemetry or first-run download.

Verify SHA256SUMS, extract the matching platform archive and run oxytype --help.
No Rust/Node/vp or source checkout required. LICENSE, attribution, third-party
notices and corresponding source accompany the release. See included README for
tested OS/terminal requirements, data paths and uninstall instructions.
